# numerical-methods

Các phương pháp số cài đặt bằng Python (môn Numerical Methods).

## Đã có
- Phương pháp chia đôi (`bisection.py`)
- Phương pháp Newton-Raphson (`newton.py`)

## Cách chạy

    python bisection.py
    python newton.py

## Chạy test

    python -m unittest

## Yêu cầu
- Python 3.8+
